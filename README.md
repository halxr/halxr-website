# halxr-website

Marketing site for Halxr, aimed at accelerator programs and investors. Plain HTML/CSS, hosted on GitHub Pages.

- Edit `index.html` (content) and `styles.css` (look). No build step.
- Preview locally: `python -m http.server 8000 --bind 127.0.0.1`, then open http://127.0.0.1:8000
- Every push to `main` redeploys the site.
